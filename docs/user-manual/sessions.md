# Sessions

Guide to creating complete, accurate workout logs.

## Session Flow

- Start a new session.
- Add one or more exercises.
- Log sets, reps, and weight.
- Finish and save the session.

## Good Logging Habits

- Log immediately after each set for accuracy.
- Keep naming consistent for exercises.
- Review the result in [Progress](progress.md).
