# Programs

How to structure and follow training plans over time.

## Program Workflow

- Create a program.
- Review available programs.
- Follow a selected program during sessions.
- Apply progression logic consistently.

## Best Practices

- Keep program names clear and goal-oriented.
- Pair programs with regular [Sessions](sessions.md) logs.
- Validate outcomes in [Progress](progress.md).
